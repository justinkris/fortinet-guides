Chapter Overview

OSPF Link-State Routing

OSPF (Open Shortest Path First) is a link-state protocol where every router maintains a Link State Database (LSDB) — a complete map of the network topology. Each router advertises its local links as Link State Advertisements (LSAs) that flood through the OSPF domain. All routers run Dijkstra's SPF algorithm on their identical LSDB copies to independently calculate the shortest path tree, ensuring loop-free routing without relying on distance-vector hop counts.

OSPF scales through a hierarchical area design. Area 0 (backbone) is mandatory — all other areas connect to it. ABRs (Area Border Routers) connect non-backbone areas to Area 0 and summarize LSAs at the boundary. ASBRs (Autonomous System Boundary Routers) import external routes into OSPF. On multi-access networks (like Ethernet), a DR (Designated Router) and BDR (Backup DR) are elected to reduce LSA flooding — all other routers form adjacencies only with DR/BDR rather than every neighbor. FortiGate supports ECMP (Equal-Cost Multi-Path) for OSPF, load-balancing across multiple equal-cost paths.

BGP Autonomous Systems

BGP (Border Gateway Protocol) is the routing protocol of the internet — a path-vector protocol that exchanges reachability information between Autonomous Systems (ASes). Each AS is assigned a unique AS number (ASN) and announces its address prefixes to neighbors via BGP UPDATE messages. Unlike OSPF (which optimizes for shortest path), BGP selects routes based on a rich set of attributes that can be tuned for policy.

eBGP (external BGP) runs between routers in different ASes; iBGP (internal BGP) runs between routers within the same AS to distribute externally learned routes internally. Key BGP attributes: LOCAL_PREF (higher is preferred, influences outbound path selection within an AS), MED (Multi-Exit Discriminator) (lower is preferred, hints to neighbors about preferred entry points), AS_PATH (shorter path preferred, also used for loop prevention). Route maps on FortiGate let you match prefixes and set attributes to implement policy routing.

iBGP rule: Routes learned via iBGP are not re-advertised to other iBGP peers (split-horizon). In large networks this requires either a full mesh of iBGP sessions or a route reflector — a designated peer that re-advertises iBGP routes to its clients.

Route Redistribution & Filtering

Route redistribution moves routes learned by one protocol into another. FortiGate can redistribute connected interfaces, static routes, OSPF routes, and BGP routes into any other routing protocol. Without careful filtering, redistribution can cause routing loops or suboptimal path selection — every redistributed route should have an explicit route map or prefix list to control exactly which prefixes are accepted and what attributes they carry.

Prefix lists match specific network prefixes with optional length qualifiers (ge/le) — they're faster and more precise than ACL-based matching for routing policy. Route summarization at area or AS boundaries reduces the routing table size and limits LSA propagation. Administrative distance (AD) determines which protocol's route wins when multiple protocols learn the same prefix — lower AD wins (connected=0, static=10, OSPF=110, BGP=200). FortiGate uses AD to resolve protocol conflicts without explicit redistribution.
