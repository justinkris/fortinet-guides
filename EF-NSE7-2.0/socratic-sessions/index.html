How to Use This Study Plan
1
Set up your Claude Project once

Create a Claude Project (not a regular chat). Edit the block above to suit your style — then copy it and paste it into the Project's Custom Instructions. This sets the persistent tutor context for every session.

2
Pick a session

Start at Session 01 and work sequentially. Each card below holds the full prompt for that subtopic — including the day count, recall from your last session, and the strict flow Claude must follow.

3
Start the Claude session

Open your Claude Project. Click "Copy Prompt" on the session card — the prompt is generated fresh with today's day count. Paste it into Claude and send. Claude will open with the story and follow the full session flow.

4
Work through the flow — let Claude lead

Don't skip steps. Let Claude ask the questions. Blurt everything you know in the recall phase. Accept corrections without defending wrong answers. The quiz at the end is honest feedback — treat it as a signal, not a grade.

5
Reflect and mark done

After the quiz, come back here and click "Mark Done" so progress sticks. Then rest — or go straight to the next session if you have energy.
